# Angelina Chatterjee — Portfolio 

An immersive, narrative-driven technical portfolio engineered with React, Vite, and GSAP. 

Built to break away from standard template designs, this platform operates as a functional manifesto. It adopts a strict, high-performance visual language—inspired by obsidian aesthetics, Formula One telemetry, and brutalist engineering logic.

## Architecture & Stack

- **Core:** React 19 + Vite (for rapid HMR and optimized production builds)
- **Animation Engine:** GSAP (ScrollTrigger) & Framer Motion (for hardware-accelerated transitions)
- **3D Rendering:** Three.js & React Three Fiber (interactive engineering constructs)
- **Styling:** Vanilla CSS (Zero-dependency, high-control custom design system)
- **Services:** Formspree Integration (Serverless terminal contact forms)

## Core Features

- **Cinematic Load Sequence:** Stuttering progress telemetry and shatter-reveal mechanics.
- **Process Breakdown Module:** Interactive architectural breakdown of flagship projects, focusing strictly on problem constraints, approaches, and logic.
- **Telemetry HUD (Lap Counter):** Fixed viewport indicator tracking scroll progression through eight distinct narrative sections.
- **Terminal Modal:** A custom-built, interactive command-line interface for recruitment and collaboration inquiries, fully wired for direct submission.

## Local Development

To examine the build locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/angelina-2206/angelina-portfolio.git
   ```

2. Navigate into the directory:
   ```bash
   cd angelina-portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## Development Philosophy

> "Performance settles conversations. Everything else tends to follow."

This build intentionally avoids generic web tropes. Components are highly modularized, prioritizing clean logic and deterministic UI behavior. Every micro-animation, typography choice, and hover state is calculated to enforce a premium, cinematic user experience.

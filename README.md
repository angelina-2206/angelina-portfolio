An immersive, narrative-driven technical portfolio engineered with high-performance aesthetics and cinematic motion. This platform is not just a showcase; it is a functional manifesto of technical discipline, adopting a visual language inspired by obsidian aesthetics, brutalist engineering logic, and deep-space telemetry.

---

## ARCHITECTURE & CORE STACK

* FRONTEND FRAMEWORK: React 19 (Hooks, Context API, Modular Architecture)
* BUILD TOOL: Vite (Ultra-fast HMR and optimized asset pipeline)
* MOTION & ANIMATION: 
  - GSAP (GreenSock): Complex scroll-driven sequences and hardware-accelerated transitions.
  - Framer Motion: Declarative UI animations and entry/exit transitions.
* 3D ENGINE: Three.js (Integrated WebGL components and interactive constructs)
* STYLING STRATEGY: Vanilla CSS (Zero-dependency design system with CSS Variables)
* BACKEND / SERVICES: Formspree (Interactive terminal for serverless communications)

---

## KEY FEATURES

### HYPERSPEED ENGINE
A high-fidelity WebGL tunnel transition integrated into the hero section. Designed with interactive post-processing (Bloom, SMAA), it reacts to user hold-input to simulate "warping" through code.

### CINEMATIC BOOT SEQUENCE
A technical telemetry loading screen featuring a real-time progress counter and a smooth fade-out reveal into the immersive hero environment.

### PROCESS BREAKDOWN MODULE
An architectural breakdown of flagship projects. Unlike standard galleries, this module focuses strictly on project constraints, technical approaches, and the underlying logic of the build.

### INTERACTIVE TERMINAL MODAL
A custom-built, command-line interface (CLI) for professional inquiries. It supports custom commands (e.g., `resume`, `github`, `clear`) and handles direct data submission to the contact pipeline.

### TELEMETRY HUD (LAP COUNTER)
A fixed-viewport indicator that tracks the user's progression through eight distinct narrative sections, providing a gamified F1-inspired scroll experience.

## LOCAL INSTALLATION

Examine the build logic locally by following these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/angelina-2206/angelina-portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd angelina-portfolio
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Launch the development environment:
   ```bash
   npm run dev
   ```
